Install the APK on Android

  1. Download the APK from the button above.
  2. Open the downloaded file. If Android asks, allow installs from this browser in Settings → Apps → Special app access → Install unknown apps.
  3. Install BLINK, then turn that browser permission off again if you do not need it.
  4. If Google Play Protect shows a warning, only continue after confirming that you downloaded this file from the official BLINK GitHub release, and review the warning before choosing whether to proceed.
